# ep048 실험 기록 (2026-10-22, gpt-4.1-mini, 조건마다 10회)

과제: 가나다식품(가상) 고객센터 반품 처리를 "AI로 자동화하는 설계안(현재 흐름 + 자동화 단계)" 작성.
- 공식 매뉴얼은 4단계다.
- 실제 기록(처리 로그 12건 · 메신저 · 개인 메모)에는 숨은 일 7가지가 있다:
  1. 품질팀 단톡 사진 확인
  2. 3만 원 초과 팀장 구두 승인(시스템에 승인 칸 없음)
  3. 반복 반품 고객 개인 엑셀
  4. 냉동 회수는 택배사 사이트에 다시 입력
  5. 주문번호 없는 전화 접수
  6. 금 16시 정산 마감 → 월요일
  7. 담당자마다 순서가 다름(사진 먼저 vs 회수 먼저)
- 인터뷰(팀장)는 "매뉴얼대로, 사진은 시스템에서, 건당 5분"이라고 했다.
  - 로그상 단순 변심 건은 4~13분이었다. 사진 확인 건은 품질팀 회신 대기 때문에 접수부터 끝까지 1~3시간 걸렸다(R-1021 103분, R-1035 220분).

## 결과 (results.json)

| 조건 | 숨은 일 찾음 (평균 /7) | 인터뷰 '5분'을 사실로 씀 | 담당자별 방식 차이 | 마감 예외 | 근거 표시 |
|---|---|---|---|---|---|
| A 매뉴얼만 | 0.0 | (인터뷰 없음) | 0 | 0 | 0 |
| B + 팀장 인터뷰 | 0.0 | 10/10 | 0 | 0 | 0 |
| C + 실제 기록 | 5.4 | 6/10 | 1/10 | 6/10 | 0 |
| D + 원작 방식(근거 · 강도 · 마찰 · 숨은 정보 · 권한 · 예외 · 다른 방식 따로) | 6.8 | 0/10 | 10/10 | 9/10 | 평균 29회 |

- C에서 '5분'을 효과 계산의 기준선으로 썼다. 예: "건당 5분 → 1~2분", "처리 시간 단축 (5분 → 1~2분 내외 가능)".
- B 예시: "하루 약 30건 처리, 총 약 5분/건 소요." 매뉴얼과 인터뷰만으로는 숨은 일을 하나도 몰랐다.
- C에서 담당자별 방식 차이를 말한 1건도 "업무 표준화 · 편차 최소화"로 결론 냈다. 원작은 이유를 알기 전에는 평균 내지 말라고 한다.
- '3만 원 초과를 사람 승인 없이 자동 승인'하는 설계는 모든 조건에서 0이었다.
- D도 '인터뷰와 기록이 다르다'를 명시한 경우는 거의 없었다. 다만 5분을 사실로 쓰지 않았고, 인터뷰를 '전해 들은 말'로 표시했다.

## 채점기 (test_grade.py)

정답을 아는 보고서(7개 모두 / 0개 / 자동 승인 / 5분)로 먼저 시험했다.

결과를 읽으면서 고친 것 3가지:
1. **택배사 규칙이 너무 넓었다.** "택배사 API 연동 … 수동 클릭"을 재입력으로 셌다(A 1건 오탐) → '사이트 · 다시 입력' 등으로 좁혔다.
2. **마감 규칙이 너무 좁았다.** '정산 마감 … 다음 영업일'을 못 셌다 → 넓혔다.
3. **'5분' 규칙이 효과 계산을 놓쳤다.** "5분 → 1~2분"을 못 셌다 → 넓혔다(C 3 → 6).
   - 넓힌 규칙에서 A 1건 오탐("일정 주기(예: 5분)로 조회")이 생겼다. A는 인터뷰가 없어 이 지표를 쓰지 않는다.
