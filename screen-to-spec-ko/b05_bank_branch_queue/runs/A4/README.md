# 두둑은행 방문 예약 · 대기 현황판
    pip install -r requirements.txt
    uvicorn main:app --reload      # http://127.0.0.1:8000
첫 실행 시 가상 데이터가 duduk.db 에 자동 생성됨 (지우면 초기화).

| 화면 | 주소 | 인증 |
|---|---|---|
| 고객(예약·번호표·도착확인) | / | 없음 |
| 지점 대기 모니터 | /board | 없음 (번호표만 표시) |
| 창구 직원 | /counter | PIN 1111 (`STAFF_PIN`) |
| 지점장 | /manager | PIN 9999 (`MANAGER_PIN`) |

규칙: 예약 고객은 도착 확인 후 대기열 앞쪽(예약 시각순), 현장 고객은 도착순. 예약 시각+15분까지 미도착 시 자동 노쇼. 창구 1·2 예금, 3 대출, 4 외환, 5 전체.
