# CLAUDE.md — 두둑은행 넉넉지점 「방문 예약 · 대기 현황판」

이 폴더의 `PRD.md` 가 요구사항이다. 이 파일은 **만드는 방법과 끝났다고 말할 조건**이다.

## 스택 (바꾸지 않는다)

- Python 3 · FastAPI · uvicorn · SQLite(표준 라이브러리 `sqlite3`) · 순수 HTML/JS/CSS.
- 외부 패키지는 `fastapi` · `uvicorn` 만. CDN · 빌드 도구 · 프런트 프레임워크 금지.

## 폴더

```
main.py            FastAPI 앱 (app = FastAPI()). 시작 시 seed/*.csv → bank.db 재생성. 파일 경로는 이 파일 위치 기준 절대 경로로
static/            화면 (index.html = /, board.html = /board)
seed/              users · counters · tickets .csv — 파일 이름 · 칸 이름 · 형식(PRD 5 표)을 바꾸지 않는다
tests/test_dod.py  완료 기준. 읽기만 한다. 고치거나 지우거나 건너뛰지 않는다
```

## 실행 · 검증

```
python -m uvicorn main:app --port 8000
python -m pytest tests -q
```

- `pytest` 가 **9/9 통과**해야 끝난 것이다. 통과하지 못했으면 끝났다고 말하지 않는다.
- 테스트가 `seed/` 를 자기 데이터로 바꿔 끼우고 **다른 폴더에서** 서버를 새로 띄운다. 서버는 **시작할 때마다** CSV 를 다시 읽어야 하고, 작업 폴더에 기대면 안 된다.
- 시각은 본문의 `at` 이 먼저다. 3분 · 10분 경계는 `at` 으로 계산한다.

## 개인정보 — 응답을 기준으로 생각한다

- 가리기는 **서버에서** 한다. 화면(JS)에서 가리는 것은 가린 게 아니다 — 브라우저 개발자 도구에 그대로 보인다.
- 응답을 만들 때 "행 전체를 돌려주고 화면에서 고른다" 를 하지 않는다. **칸을 PRD 대로 골라 담는다.**
- 대기 화면에는 업무 종류도 나가지 않는다. 계좌번호 전체는 어떤 응답에도 나가지 않는다. 지점장도 고객 상세는 못 본다.

## 하지 말 것

- PRD 8 범위 밖 기능(로그인 · 금융 거래 · 알림 · 보류 복귀 · 예약 화면 · 민원 · 점검표 · 교육 · 통계 그래프 · 편집 화면 · 다크 모드)을 넣지 않는다.
- "지점장이니까 상세는 봐도 되지 않나" 는 R8 위반이다 — 403.
- "3분 전에도 일단 넘기자" 는 R4 위반이다 — 409.
- `tests/` 와 `seed/` 의 칸 이름 · 파일 이름, `data-testid` 이름, 거부 코드(400 · 403 · 404 · 409)를 바꾸지 않는다.

## 완료 보고 형식

마지막 답은 아래 형식으로만 한다. **PRD 에 없는 API · 칸 · 화면 요소를 하나라도 추가했으면 'PRD 와 다르게 한 것' 에 전부 적는다.** PRD 가 정하지 않아 직접 정한 것도 적는다.

```
DoD: 9/9 (또는 n/9, 실패한 T번호와 이유)
만든 파일: main.py, static/*, seed/*.csv
범위 밖 기능: 없음 (있으면 이름)
PRD 와 다르게 한 것: 없음 (있으면 무엇과 이유 — 추가한 API 경로 포함)
PRD 가 정하지 않아 직접 정한 것: 없음 (있으면 무엇을 어떻게)
```
