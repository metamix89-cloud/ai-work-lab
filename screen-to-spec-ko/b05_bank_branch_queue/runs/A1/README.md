# 두둑은행 방문 예약 · 대기 현황판

    pip install -r requirements.txt
    python main.py        # http://localhost:8000

| 화면 | 주소 | PIN |
|---|---|---|
| 고객 키오스크(번호표·예약·도착확인) | / | - |
| 대기 화면(모니터) | /board.html | - (번호표·업무만 표시) |
| 창구 직원 | /teller.html | 1234 (`TELLER_PIN`) |
| 지점장 | /manager.html | 9999 (`MANAGER_PIN`) |

- 최초 실행 시 현재 시각 기준 가상 데이터가 `duduk.db`에 생성됨. 초기화하려면 파일 삭제 후 재실행.
- 호출 순서: 도착 확인한 예약 고객(예약 시간순) → 현장 고객(도착순).
- 예약 시간 +15분까지 도착 확인이 없으면 노쇼. 호출 후 미응답은 창구에서 노쇼 처리.
- 지점장 화면은 이름·연락처를 마스킹해서 보여 줌. 도착 확인을 체험하려면 직접 예약(당일 가까운 시간)하세요.
