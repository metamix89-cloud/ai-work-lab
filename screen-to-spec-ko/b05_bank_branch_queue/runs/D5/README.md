# 두둑은행 방문 예약 · 대기 현황판

```
pip install -r requirements.txt
python -m uvicorn main:app --port 8000
```
첫 실행 시 `duduk.db` 가 만들어지고 가상 데이터가 들어갑니다. 초기화하려면 `duduk.db*` 삭제 후 재시작.

| 화면 | 주소 | 로그인 |
|---|---|---|
| 고객 (예약 / 번호표 / 도착 접수) | `/` | 없음 |
| 대기 화면 (공용 모니터) | `/display` | 없음 (번호 · 가린 이름 · 창구만) |
| 창구 직원 | `/teller` | 창구 1~4 / PIN 1111, 2222, 3333, 4444 |
| 지점장 | `/manager` | PIN 9999 |

PIN 은 환경변수 `TELLER_PINS="a,b,c,d"`, `MANAGER_PIN` 으로 바꿉니다 (기본값은 데모용).

데모 예약 도착 접수: `DEMO01`(010-0000-1795) · `DEMO02`(010-0000-8791) · `DEMO03`(010-0000-4548)
