# 두둑은행 방문 예약 · 대기 현황판

    pip install -r requirements.txt
    python -m uvicorn main:app --port 8000

처음 실행하면 `duduk.db`가 만들어지고 가상 데이터(현재 시각 기준)가 들어갑니다. 초기화하려면 `duduk.db`를 지우고 다시 실행하세요.

| 화면 | 주소 | 비고 |
|---|---|---|
| 고객 (예약 / 번호표 / 도착 확인) | http://localhost:8000/ | |
| 대기 화면 (공용 모니터) | /static/display.html | 번호표·업무·창구만 표시, 개인정보 없음 |
| 창구 직원 | /static/teller.html | PIN `1111` (환경변수 `TELLER_PIN`) |
| 지점장 | /static/manager.html | PIN `9999` (환경변수 `MANAGER_PIN`) |

## 규칙
- 대기 순서: 도착 확인한 예약 고객(예약 시각순) → 현장 번호표(도착순).
- 예약 30분 전부터 도착 확인 가능, 예약 시각 + 15분까지 미도착이면 노쇼.
- 호출 후 응대가 없으면 창구에서 노쇼 처리. 지점장 화면의 노쇼 내역은 이름·전화·계좌가 마스킹됨.
- 창구별 업무: 1=예금, 2=예금·대출, 3=대출, 4=외환·예금 (`main.py`의 `COUNTERS`).
- 예약 시간대는 09:00~16:00 (30분 단위, 시간당 3팀). 영업시간 밖에 실행하면 예약 가능한 시간이 없음.
