# 다온소프트 사내 소식 피드

## 실행

```
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

http://127.0.0.1:8000 접속 (API 문서: /docs)

- 첫 실행 시 `feed.db`(SQLite)가 생성되고 가상 직원 12명·글 70여 개·댓글이 자동 입력됩니다. 초기화하려면 `feed.db`를 삭제하세요.
- 상단 드롭다운으로 사용자를 바꿔 가며 테스트합니다 (★ 표시가 운영자). 데모용 인증이라 `X-User-Id` 헤더만 확인하므로, 실서비스에서는 SSO/세션으로 교체해야 합니다.

## 규칙

- 공지 고정/해제: 운영자만
- 삭제: 본인 글·댓글만 (운영자도 남의 글은 삭제 불가)
- 신고: 글당 1인 1회, 본인 글 불가. 3건 이상이면 일반 직원 화면에서 숨김 (운영자는 신고 수와 함께 계속 볼 수 있음)
- 목록: 고정글 → 최신순, 20개씩 '더 보기' (커서 방식)
