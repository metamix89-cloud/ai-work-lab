- **A 셋 다 요청자를 '로그인' 으로 묻는다**(9 · 11 · 12편 세 편 연속). A1 · A2 는 `/api/login` · 비밀번호 · 세션, A3 은 비밀번호 없이 `X-User-Id` 헤더("인증(데모) … 실서비스에서는 세션/SSO 로 교체할 것") — 헤더가 없으면 401. 테스트는 PRD 계약(`user` · `viewer`)으로 부르니 셋 다 401.
- **'더 보기' 는 A 셋 다 커서였다** — A1 · A2 `WHERE p.id < :before ORDER BY p.id DESC LIMIT 21`, A3 자체 커서 문자열. 쪽 번호(offset)로 나눠 새 글이 올라올 때 겹치는 실수(함정 앱 T3)는 **아무도 하지 않았다.** 11편 동시성에 이어 **두 편 연속 기대한 실패가 안 나왔다** — 솔직하게 적는다. (A 는 id 순, PRD 는 created_at 순 — 시드에 시각이 같은 글이 있으면 다를 수 있으나 A 는 자기 데이터라 문제 없음.)
- **삭제: A 셋 다 '내 글만' — 운영자도 남의 글을 못 지운다.** A1 `if post.author_id != user.id: 403 "내가 쓴 글만 삭제할 수 있습니다"`(A2 · A3 같음). 한 줄 요청의 "자기 글만 지울 수 있고" 를 **글자 그대로** 따랐다. 신고가 쌓인 글을 운영자가 치울 방법이 없다. PRD R4 는 "자기 글은 직원도, 남의 글은 운영자만".
- **고정: A 셋 다 개수 제한 없음**(운영자 확인만). PRD R5 는 최대 3개 — '공지가 너무 많으면 공지가 아니다'.
- **신고: 자동 숨김은 A3 하나**(`HIDE_AT_REPORTS = 3`). A1 · A2 는 숨기지 않고 운영자 신고 목록(`/api/reports`, 범위 밖 '신고 처리 화면')을 만들었다. 자기 글 신고 거부 · 중복 신고 409 는 셋 다 했다.
- A 셋 다 댓글 삭제 API 를 더했다(PRD 에 없음).

## 탐침 — 결과물끼리 같은 요청 (`probe_cases.py` + `probe_feed.json`)

| 보낸 것 | B1 · B2 · B3 · C1 · C2 · C3 · 정답 앱 |
|---|---|
| 셋째 신고로 숨긴 글에 다른 직원이 댓글 | **201 — 일곱 다 받는다** |
| 이미 고정된 글을 다시 고정 | 200 (PRD 대로) |

- **B · C 여섯이 처음으로 탐침 전부에서 같은 답을 냈다** — PRD R1~R8 이 거부 순서 · 상태를 다 정했기 때문.
- 남은 틈 하나: **숨긴 글에 댓글이 달린다**(일곱 다, 우리 정답 앱 포함). 화면에서는 안 보이는 글에 API 로 댓글 · 신고가 들어간다. **C1 이 '직접 정한 것' 에 적었다** — "숨겨진 글에도 댓글과 추가 신고는 받습니다". PRD 가 정하지 않은 자리를 모두 같은 쪽으로 메웠고, 그걸 말해 준 건 C1.

## C 의 '직접 정한 것' (두 번째 편)

- C1 · C3: **"새 글의 시각은 서버의 지금, 다만 기존 글의 최신 시각보다 이르면 그 시각으로"** — 서버 시계가 시드 날짜(10/20)보다 과거면 새 글이 맨 앞에 안 오는 문제를 스스로 막았다(PRD 는 "시각은 서버의 지금" 만).
- 삭제 방식: C1 · C3 은 행을 지우고 댓글 · 신고도 함께, C2 는 '삭제 표시' 만(id 재사용 방지). C2 "삭제한 글은 고정이 풀립니다", "고정 3개 수는 삭제되지 않은 고정 글 기준".
- 커서 형식은 C 셋 다 `"created_at|post_id"` — 정답 앱과 같은 모양.
- C3 은 PRD 가 testid 를 안 정한 '다시 시도' 버튼에 `data-testid="retry"` 를 붙였다고 'PRD 와 다르게 한 것' 에 적었다.

## 숫자의 뜻

- 권한 문장은 **'누가 누구의 것을'** 까지 — "자기 글만 지울 수 있다" 만 쓰면 운영자도 못 지운다(3/3). 
- 개수 제한(고정 3개) · 자동 처리 기준(신고 3명)은 **숫자로**. 안 쓰면 제한 없음(3/3) · 자동 숨김 없음(2/3).
- '더 보기' · 동시성 같은 **잘 알려진 함정은 AI 가 스스로 피한다**(두 편 연속). PRD 가 지켜야 할 곳은 **회사마다 다른 규칙**(누가 지우나 · 몇 개 · 몇 명)이다.
