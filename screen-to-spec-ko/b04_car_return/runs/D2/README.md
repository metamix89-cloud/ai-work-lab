# 부릉부릉렌터카 반납 점검표

FastAPI + SQLite + 바닐라 HTML/JS. 처음 실행하면 가상 데이터가 자동으로 들어갑니다.

```
pip install -r requirements.txt
python -m uvicorn app.main:app --reload      # http://localhost:8000
python -m pytest                              # 테스트 26개
```

데모 계정: 직원 `staff / staff1234`, 고객 `kim / kim1234`, `lee / lee1234`, `park / park1234`.
초기화하려면 `data/` 폴더를 지우고 다시 실행하세요.

## 요금 규칙 (`app/billing.py`)
| 항목 | 규칙 |
|---|---|
| 지연 | 예정 + 30분까지 0원. 31분째부터 1시간 블록마다 10,000원(31~90분 1블록, 91~150분 2블록…), 상한 80,000원. 일찍 반납해도 환불 없음 |
| 연료 | 대여 시보다 모자란 칸당 15,000원. 더 채워도 환불 없음 |
| 손상 | 경미 30,000 / 중간 150,000 / 심각 500,000. 사진 없는 흠집은 접수 거부. 대여 전부터 있던 흠집은 기록만 남기고 0원 |

## 판단한 부분 (규칙에 명시되지 않은 것)
- **대여 전 흠집 판정**: 직원이 반납 폼에서 대여 시 기록된 흠집과 "동일"로 연결해야만 0원입니다. 서버는 클라이언트의 "기존 흠집" 플래그를 믿지 않고, 연결 대상이 같은 대여 건·같은 부위인지 검증합니다.
- **악화된 흠집**: 연결한 흠집의 등급이 대여 때보다 높으면 거부하고 "새 흠집으로 등록"을 요구합니다(전액 청구). 차액만 청구하길 원하면 `service.py`에서 바꾸면 됩니다.
- **지연 분 계산**: 초는 버립니다(30분 59초 지연 = 유예).
- **확정 후 수정 불가**: 반납은 한 번만 확정됩니다(재요청은 409). 정정 기능은 없습니다.
- 반납 시각은 한국 시간 기준이며 미래 시각(5분 초과)은 거부합니다.
- 새 대여 등록 화면은 없습니다. 대여 시 흠집은 시드 데이터로만 들어갑니다.
