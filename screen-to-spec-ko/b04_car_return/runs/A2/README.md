# 부릉부릉렌터카 반납 점검표

FastAPI + 바닐라 HTML/JS + SQLite.

```
pip install -r requirements.txt
python -m uvicorn app.main:app --port 8000     # http://127.0.0.1:8000
python -m app.seed --reset                      # 데모 데이터 초기화
python -m pytest tests
```

첫 실행 시 `data/rental.db` 가 자동 생성되고 가상 데이터가 들어갑니다.

| 역할 | 계정 |
|---|---|
| 직원 | staff1 / staff1234, staff2 / staff1234 |
| 고객 | hong / cust1234, kim / cust1234, park / cust1234 |

## 요금 규칙 (`app/billing.py` 상단 상수로 조정)
- **지연**: 30분 유예 후 초과 1시간(올림)당 일 요금의 10%, 24시간 구간마다 일 요금 1일치가 상한
- **연료**: 대여 시 눈금보다 부족한 1/8 당 `탱크용량/8 L × 1,800원 × 1.5`
- **손상**: 1등급 30,000 / 2등급 120,000 / 3등급 400,000원
- **기존 흠집**: 대여 시점에 기록된 같은 부위 흠집과 1:1로 짝지어 같은 등급 이하면 0원, 악화됐으면 등급 차액만 청구.
  판단은 서버가 DB의 대여 시점 기록으로만 하며 클라이언트 입력은 신뢰하지 않음.
- 주행거리는 기록·검증(대여 시작값 이상)만 하고 요금에는 반영하지 않음.

## 권한
- 고객: 본인 대여 건·청구·그 사진만 조회 (타인 건은 404). 반납 처리·사진 업로드 불가.
- 직원: 전체 조회, 반납 점검(미리보기 → 확정). 확정은 1회만 가능(재제출 409), 확정 후 수정 불가.
