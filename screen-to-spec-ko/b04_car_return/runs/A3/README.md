# 부릉부릉렌터카 반납 점검표

FastAPI + 바닐라 HTML/JS + SQLite. 첫 실행 시 가상 데이터가 자동으로 들어갑니다.

```
pip install -r requirements.txt
python -m uvicorn app.main:app --port 8000      # → http://localhost:8000
python -m pytest -q                              # 테스트
```
데이터 초기화: `data/` 폴더 삭제 후 재실행.

## 데모 계정 (비밀번호 전부 `demo1234`)
| 역할 | 아이디 |
|---|---|
| 직원 | `staff1`, `staff2` |
| 고객 | `minjun`(김민준), `seoyeon`(이서연), `jihun`(박지훈) |

## 요금 규칙 (`app/calc.py` 상단 상수에서 변경)
- **지연**: 유예 30분 이내 0원. 초과 시 반납 예정 시각부터 1시간(올림)당 일 대여료의 10%, 24시간 블록마다 일 대여료가 상한.
- **연료**: 게이지 8칸 기준 부족한 칸 × (탱크 L ÷ 8) × 3,000원/L. 더 채워 와도 환급 없음.
- **손상**: 등급(1 경미 5만 / 2 보통 15만 / 3 심각 40만) × 부위 계수(유리 1.5, 범퍼 1.2 …).
- **대여 전 흠집**: 대여 시작 시 기록된 흠집(`damages.phase='pickup'`)과 같은 부위에 같거나 낮은 등급이면 0원(`pre_existing`), 등급이 올라가면 차액만(`worsened`), 없던 부위면 전액(`new`).
- 청구되는 흠집에는 사진 필수. 반납 확정은 한 번만 가능(재시도 시 409).

## 접근 제어
- 고객은 `customer_id` 가 본인인 대여 건·청구서·사진만 조회(남의 건은 404). 반납 처리·사진 업로드는 직원 전용.
- 세션은 HttpOnly 쿠키, 비밀번호는 PBKDF2, 업로드는 매직바이트로 JPEG/PNG/WEBP만 허용(5MB), 파일명은 서버가 생성.
