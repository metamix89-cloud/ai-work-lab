## 요금 규칙 (`app/billing.py`에서 수정)
- **지연**: 30분 유예 후 1시간(올림)당 일 요금의 10%, 24시간 단위로 하루치 상한.
- **연료**: 게이지 1/8칸 단위. 대여 시보다 부족한 칸 × (탱크 용량/8) × 2,000원/L + 주유 대행 10,000원. 더 채워 와도 환급 없음.
- **손상**: 1등급(경미) 50,000 / 2등급(보통) 150,000 / 3등급(심각) 400,000원, 부위당 1건.
- **대여 전 흠집 제외**: 대여 시작 시 차량의 기존 흠집을 대여 건에 고정(스냅샷). 반납 시 같은 부위·같은 등급 이하는 0원, 등급이 올라가면 차액만 청구. 반납 때 확정된 흠집은 차량 이력에 반영되어 다음 대여의 '기존 흠집'이 됩니다.

## 권한
- 직원: 전체 대여 건 조회, 새 대여 등록, 반납 점검·확정, 사진 업로드.
- 고객: 본인 대여 건·청구 내역·관련 사진만 조회(타인 건은 404).
