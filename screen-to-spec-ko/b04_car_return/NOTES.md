## 코드로 읽은 규칙 — A 와 D (`scan_rules.py` + 상수 줄)

| 규칙 | A 한 줄 (3회) | D 한 줄 + 숫자 (3회) | PRD |
|---|---|---|---|
| 유예 | **30분 3/3** (A1 `GRACE_MINUTES = 30` · A2 `GRACE_MIN = 30` · A3 30) — 업계 관행 | 30분 3/3 | 30분 |
| 지연 요금 | 3/3 "1시간(올림)당 **일 요금의 10%**, 하루치 상한" — 숫자가 아니라 비율 | 1만 · 상한 8만 3/3 — **그러나 3/3 '유예 끝난 뒤부터' 시간을 셈**(31~90분 1만 · 91~150분 2만). D3 보고: "31분과 90분은 1만 원, 91분은 2만 원" | 예정 시각부터 시작된 1시간(61분 → 2만, 150분 → 3만) |
| 연료 | 3/3 **리터 × 단가**(2,000 · 1,800×1.5 · 3,000원/L, A1 은 주유 대행비 1만 추가) | 칸당 1.5만 3/3 | 칸당 1.5만 |
| 손상 | 3/3 세 등급, 금액 제각각(5/15/40만 · 3/12/40만 · 5/15/40만 × 부위 계수) | 3/15/50만 3/3 | 3/15/50만 |
| 대여 전 손상 | **3/3 제외** + 3/3 "같은 부위가 더 심해졌으면 **차액만**" (A1 · A2 · A3 전부) | 3/3 제외, D1 · D3 차액 규칙 스스로 추가 | 부위가 같으면 0원(등급 무관) |
| 사진 없는 손상 | **1/3 만 거절**(A3 "청구되는 흠집에는 사진 필수"; A1 · A2 는 사진 선택) | 3/3 거절 | 400 |
| 로그인 | 3/3 | 3/3 | 범위 밖 |

- **D 의 핵심 발견:** 숫자를 다 줘도 **"시간을 어디서부터 세나"** 가 갈렸다. 제가 D 에 준 문장 "30분까지는 유예(0원), 31분부터 시작된 1시간마다 10,000원" 을 셋 다 '유예 뒤 구간' 으로 읽었다(31~90분 = 1블록). PRD 는 같은 규칙을 "31분 → 10,000 · 61분 → 20,000" **예시 두 개**로 적었고 B · C 여섯은 전부 PRD 대로(60분 → 1만, 61분 → 2만: T3 + 탐침). → **숫자가 아니라 예시가 계약이다.**
- A 는 네 편 연속 '교과서 규칙은 안다'(유예 · 기존 손상 제외) 에 더해 **우리보다 정교한 규칙**(악화 차액)까지 넣었다. 대신 회사 숫자(정액 1만 · 칸당 1.5만 · 3/15/50만)는 하나도 못 맞췄고, 지연은 셋 다 '일 요금의 10%' 라는 **다른 체계**를 골랐다.
- A · D 모두 사진 **업로드**를 만들었다(한 줄에 '사진' 이 있어서). PRD 는 '사진은 장수만' 으로 범위 밖에 뒀다 — 한 단어가 기능 하나를 부른다.
- 로그인은 2부 네 편 연속 A 3/3 (이번엔 D 도 3/3).

## 숫자의 뜻

- **회사 숫자를 주는 것(D)으로는 부족하다.** 숫자 7개를 다 맞추고도 경계 해석이 셋 다 PRD 와 달랐다. PRD 가 한 일은 숫자 + **예시 두 줄** + 테스트. 2부 세 편의 결론("갈리는 건 회사 숫자") 에서 한 발 더: **숫자 옆에 예시**.
- **PRD 는 AI 의 상식도 덮는다.** 한 줄 요청이 스스로 넣은 '악화 차액' 을 PRD 받은 여섯은 전부 버리고 0원. 그게 회사가 원하는 건지는 **PRD 쓴 사람이 결정했어야** 한다 — 이번 PRD 는 그 질문을 안 했다(다음 편 교훈: '기존 손상이 더 심해졌으면?' 한 줄).
- 탐침이 처음 갈린 자리(부위 이름 서버 제한)도 같은 종류 — 화면에 적은 선택지가 서버의 규칙인지 PRD 가 말하지 않았다.
