# CLAUDE.md — 가나다식품 「소호 쇼핑몰 상품 목록 · 장바구니」

이 폴더의 `PRD.md` 가 요구사항이다. 이 파일은 **만드는 방법과 끝났다고 말할 조건**이다.

## 스택 (바꾸지 않는다)

- Python 3 · FastAPI · uvicorn · SQLite(표준 라이브러리 `sqlite3`) · 순수 HTML/JS/CSS.
- 외부 패키지는 `fastapi` · `uvicorn` 만. CDN · 빌드 도구 · 프런트 프레임워크 금지. 금액은 정수 원.

## 폴더

```
main.py            FastAPI 앱 (app = FastAPI()). 시작 시 seed/*.csv → shop.db 재생성
static/index.html  화면 (JS 는 이 파일 안이나 static/app.js)
seed/              products.csv · options.csv — 파일 이름 · 칸 이름 · 형식(PRD 5 표)을 바꾸지 않는다
tests/test_dod.py  완료 기준. 읽기만 한다. 고치거나 지우거나 건너뛰지 않는다
```

## 실행 · 검증

```
python -m uvicorn main:app --port 8000
python -m pytest tests -q
```

- `pytest` 가 **9/9 통과**해야 끝난 것이다. 통과하지 못했으면 끝났다고 말하지 않는다.
- 테스트가 `seed/` 를 자기 데이터로 바꿔 끼우고 서버를 새로 띄운다. 서버는 **시작할 때마다** CSV 를 다시 읽어야 한다.
- 품절 · 옵션 · 수량 한도 · 합계 · 배송비는 **서버(API)** 가 정한다. 화면은 서버가 준 합계를 그린다(JS 로 따로 세지 않는다).

## 하지 말 것

- PRD 8 범위 밖 기능(로그인 · 결제 · 쿠폰 · 검색 · 상세 페이지 · 리뷰 · 찜 · 편집 화면 · 재고 차감 · 이미지 · 다크 모드)을 넣지 않는다.
- "품절이어도 담아 두면 입고 때 편할 텐데" · "재고가 모자라면 있는 만큼만 담아 주자" 는 R1 · R4 위반이다. 거부하고 이유를 돌려준다.
- 장바구니에 담을 때 재고를 줄이지 않는다.
- `tests/` 와 `seed/` 의 칸 이름 · 파일 이름, `data-testid` 이름, 거부 코드(400 · 404 · 409)를 바꾸지 않는다.

