# 다온소프트 신입사원 온보딩 교육

FastAPI + SQLite + 순수 HTML/JS.

## 실행
```
pip install fastapi uvicorn
uvicorn main:app --reload
```
http://127.0.0.1:8000 접속. 최초 실행 시 `onboarding.db`가 가상 데이터와 함께 자동 생성됩니다. (초기화: db 파일 삭제 후 재시작)

## 데모 계정
| 구분 | 사번 | 비밀번호 |
|---|---|---|
| 신입 12명 | N2610 ~ N2621 | 1234 |
| 인사팀 | HR001 | hr1234 |

신입 상태 예: N2610 수료 / N2615 퀴즈 대기 / N2612 퀴즈 불합격 / N2613 수강 중(3/4) / N2616 미시작

## 규칙
- 레슨 1→4 순서대로 수강 (서버에서 검증, 건너뛰기 불가)
- 4개 완료 후 퀴즈(10문항) 응시, 80점 이상이면 수료, 재응시 가능
- 인사팀은 로그인하면 미수료자 목록(진행 상태·최고 점수·응시 횟수) 확인
- 정답은 서버에서만 채점하며 클라이언트에 노출되지 않음
