## 실수 1 — 첫 실측이 오염됐다 (2026-10-23)

`runs/` 를 lab 폴더 안에 두고 돌렸더니 **한 줄 요청(A)도 9/9** 가 나왔다. 마지막 답이 CLAUDE.md 의 완료 보고 형식 그대로였다.
Claude Code 는 **상위 폴더의 CLAUDE.md 를 자동으로 읽는다.** 빌더가 `..` 의 CLAUDE.md · PRD.md · tests/ 를 찾아 `APP_DIR` 로 자기 폴더를 가리켜 pytest 까지 돌렸다.
→ 빌드 작업 폴더를 CLAUDE.md 가 하나도 없는 임시 폴더로 옮기고(`run_build.py neutral_root`), 끝난 뒤 `runs/` 로 옮긴다. 오염된 9회는 `runs_contaminated/` 에 그대로 둔다(증거).
배운 것: 실험 조건을 '폴더에 뭐가 있나' 로 나누면, 상위 폴더까지 조건이다.
