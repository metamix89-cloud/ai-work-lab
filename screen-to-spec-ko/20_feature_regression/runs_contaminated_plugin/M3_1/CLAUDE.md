# CLAUDE.md — 다온소프트 「회의실 예약」 (v2 작업)

이 폴더에는 **이미 돌고 있는 앱(v1)** 이 있다. `PRD.md` 는 v2 로 고친 요구사항이고, `[v2]` 표시가 붙은 줄이 이번에 할 일이다. 이 파일은 **고치는 방법과 끝났다고 말할 조건**이다.

## 스택 (바꾸지 않는다)

- Python 3 · FastAPI · uvicorn · SQLite(표준 라이브러리 `sqlite3`) · 순수 HTML/JS/CSS.
- 외부 패키지는 `fastapi` · `uvicorn` 만. CDN · 빌드 도구 · 프런트 프레임워크 금지.

## 폴더

```
main.py            FastAPI 앱 (app = FastAPI()). 시작 시 seed/*.csv → rooms.db 재생성
static/index.html  화면
seed/              rooms.csv · users.csv · reservations.csv — 파일 이름 · 칸 이름 · 칸 수를 바꾸지 않는다
tests/test_dod.py  v1 의 완료 기준 9개. 읽기만 한다. 고치거나 지우거나 건너뛰지 않는다
```

## 실행 · 검증

```
python -m uvicorn main:app --port 8000
python -m pytest tests -q
```

- **고치기 전에 먼저 `pytest` 를 돌려 9/9 인지 본다.** 고친 뒤에 다시 돌려 **기존 9개가 그대로 9/9** 여야 끝난 것이다. 하나라도 떨어지면 끝났다고 말하지 않는다. 테스트가 아니라 **앱을** 고친다.
- 새 완료 기준 T10~T12(PRD 10)는 테스트 파일이 없다. 확인하려면 `tests/test_recur.py` 를 **새로** 만들어도 된다. `tests/test_dod.py` 는 건드리지 않는다.
- 규칙 검사는 **서버(API)** 가 한다. 화면에서 막는 것은 안내일 뿐이다.

## 하지 말 것

- PRD 8 범위 밖 기능을 넣지 않는다. "있으면 좋을" 것은 넣지 않는다.
- v1 의 손잡이를 바꾸지 않는다: `data-testid` · `data-room` · `data-start` · `data-state` 의 이름과 값, API 경로, 요청 · 응답의 기존 칸 이름, 거부 응답의 상태 코드와 `detail` 문구, `seed/` 의 파일 · 칸 이름. **더하기만 하고 바꾸지 않는다.**
- 이번 일과 상관없는 코드를 정리하거나 고쳐 쓰지 않는다.
