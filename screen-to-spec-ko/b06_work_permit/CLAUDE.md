# CLAUDE.md — 뚝딱건설 해뜰현장 「위험 작업 허가서」

이 폴더의 `PRD.md` 가 요구사항이다. 이 파일은 **만드는 방법과 끝났다고 말할 조건**이다.

## 스택 (바꾸지 않는다)

- Python 3 · FastAPI · uvicorn · SQLite(표준 라이브러리 `sqlite3`) · 순수 HTML/JS/CSS.
- 외부 패키지는 `fastapi` · `uvicorn` 만. CDN · 빌드 도구 · 프런트 프레임워크 금지.

## 폴더

```
main.py            FastAPI 앱 (app = FastAPI()). 시작 시 seed/*.csv → permit.db 재생성. 파일 경로는 이 파일 위치 기준 절대 경로로
static/index.html  화면 (JS 는 이 파일 안이나 static/app.js)
seed/              users · zones · check_items · permits .csv — 파일 이름 · 칸 이름 · 형식(PRD 5 표)을 바꾸지 않는다
tests/test_dod.py  완료 기준. 읽기만 한다. 고치거나 지우거나 건너뛰지 않는다
```

## 실행 · 검증

```
python -m uvicorn main:app --port 8000
python -m pytest tests -q
```

- `pytest` 가 **9/9 통과**해야 끝난 것이다. 통과하지 못했으면 끝났다고 말하지 않는다.
- 테스트가 `seed/` 를 자기 데이터로 바꿔 끼우고 **다른 폴더에서** 서버를 새로 띄운다. 서버는 **시작할 때마다** CSV 를 다시 읽어야 하고, 작업 폴더에 기대면 안 된다. 테스트 데이터의 시각은 **실행하는 시각 기준**(지금 −9시간 · +2시간 등)이다.
- 상태 · 권한 · 만료 · 상충은 **서버(API)** 가 정한다. 화면은 서버가 준 상태를 그린다 — 화면에서 만료를 계산하거나 단추만 숨기는 것으로 막지 않는다.
- 만료는 **서버 시계**로 본다. `valid_until` 은 승인 때 한 번 적고(승인 + 8시간, 당일 23:59 상한), 읽을 때마다 지금과 비교해 `expired` 로 보여 준다.

## 하지 말 것

- PRD 8 범위 밖 기능(로그인 · 반려 · 연장 · 첨부 · 알림 · 서명 · 가스 측정 · 출역 · 자재 · 점검표 · 통계 · 편집 화면 · 다크 모드)을 넣지 않는다.
- "책임자니까 자기 허가도 승인하게 하자" 는 R3 위반이다 — 403.
- "만료됐으면 자동으로 연장해 주자" 는 R5 위반이다 — 409, 연장은 새 허가.
- "검토를 건너뛰고 바로 승인" 은 R4 위반이다 — 409.
- `tests/` 와 `seed/` 의 칸 이름 · 파일 이름, `data-testid` 이름, 거부 코드(400 · 403 · 404 · 409)를 바꾸지 않는다.

## 완료 보고 형식

마지막 답은 아래 형식으로만 한다. **PRD 에 없는 API · 칸 · 화면 요소를 하나라도 추가했으면 'PRD 와 다르게 한 것' 에 전부 적는다.** PRD 가 정하지 않아 직접 정한 것도 적는다.

```
DoD: 9/9 (또는 n/9, 실패한 T번호와 이유)
만든 파일: main.py, static/index.html, seed/*.csv
범위 밖 기능: 없음 (있으면 이름)
PRD 와 다르게 한 것: 없음 (있으면 무엇과 이유 — 추가한 API 경로 포함)
PRD 가 정하지 않아 직접 정한 것: 없음 (있으면 무엇을 어떻게)
```
