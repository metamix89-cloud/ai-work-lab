# CLAUDE.md — 가나다식품 「경영 현황 대시보드」

이 폴더의 `PRD.md` 가 요구사항이다. 이 파일은 **만드는 방법과 끝났다고 말할 조건**이다.

## 스택 (바꾸지 않는다)

- Python 3 · FastAPI · uvicorn · SQLite(표준 라이브러리 `sqlite3`) · 순수 HTML/JS/CSS.
- 외부 패키지는 `fastapi` · `uvicorn` 만. 차트 라이브러리 · CDN · 빌드 도구 · 프런트 프레임워크 금지.

## 폴더

```
main.py            FastAPI 앱 (app = FastAPI()). 시작 시 seed/*.csv → biz.db 재생성
static/index.html  화면 (JS 는 이 파일 안이나 static/app.js)
seed/              users · orders · stock · inquiries .csv — 파일 이름 · 칸 이름 · 형식(PRD 5 표)을 바꾸지 않는다
tests/test_dod.py  완료 기준. 읽기만 한다. 고치거나 지우거나 건너뛰지 않는다
```

## 실행 · 검증

```
python -m uvicorn main:app --port 8000
python -m pytest tests -q
```

- `pytest` 가 **9/9 통과**해야 끝난 것이다. 통과하지 못했으면 끝났다고 말하지 않는다.
- 테스트가 `seed/` 를 자기 데이터로 바꿔 끼우고 서버를 새로 띄운다. 서버는 **시작할 때마다** CSV 를 다시 읽어야 한다. 테스트 데이터의 날짜는 **실행하는 날 기준**으로 만든다.
- 지표 계산 · 기간 · 역할별 숨김은 **서버(API)** 가 한다. 화면이 카드를 숨겨도 응답에 값이 있으면 숨긴 게 아니다(T7 이 응답을 읽는다).
- 기간 끝날을 `ordered_at <= '2026-10-24'` 처럼 **문자열로 비교하면 그날 주문이 빠진다**(T5).

## 하지 말 것

- PRD 8 범위 밖 기능(로그인 · 입력 · 내려받기 · 드릴다운 · 목표 대비 · 원가 · 알림 · 자동 새로고침 · 권한 편집 · 다크 모드)을 넣지 않는다.
- "매출은 주문 금액 합이 더 직관적" · "취소율 분모가 0 이면 0% 로 보여 주자" 는 R3 · R4 위반이다.
- 1편과 같은 지표(주문 수 · 재고 경고)의 식을 바꾸지 않는다.
- `tests/` 와 `seed/` 의 칸 이름 · 파일 이름, `data-testid` 이름, 거부 코드(400 · 404)를 바꾸지 않는다.

## 완료 보고 형식

마지막 답은 아래 형식으로만 한다. **PRD 에 없는 API · 칸 · 화면 요소를 하나라도 추가했으면 'PRD 와 다르게 한 것' 에 전부 적는다.** PRD 가 정하지 않아 직접 정한 것도 적는다.

```
DoD: 9/9 (또는 n/9, 실패한 T번호와 이유)
만든 파일: main.py, static/index.html, seed/*.csv
범위 밖 기능: 없음 (있으면 이름)
PRD 와 다르게 한 것: 없음 (있으면 무엇과 이유 — 추가한 API 경로 포함)
PRD 가 정하지 않아 직접 정한 것: 없음 (있으면 무엇을 어떻게)
```
