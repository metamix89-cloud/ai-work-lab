# PRD — 한빛요양병원 「당직 순번표」

> 「이 화면, PRD 로는 이렇게」 4편. 병원 · 직원 · 일정은 모두 교육용 가상 데이터.
> 형식은 10칸(개요 · 사용자 · 기능 · 화면 · 데이터 · 업무 규칙 · 제약 · 범위 밖 · 개발 단계 · 완료 기준).

## 1. 개요

- **배경:** 한빛요양병원 3병동 간호팀(6명)은 매달 야간 당직 순번을 수간호사가 손으로 짠다. 휴가 · 교육일을 피하고, 연속 당직을 피하고, 주말을 고르게 나누다 보면 하루가 간다. 그리고 "왜 나만 주말 셋이에요" 가 나온다.
- **목적:** 버튼 하나로 **한 달 순번을 규칙대로 생성**하고, 사람끼리 **바꾸기**는 규칙 안에서만 허용하며, 누가 몇 번 · 주말 몇 번인지 **숫자로 보인다.**
- **성공 기준:** 순번 짜기 1시간 → 1분. "왜 나만" 이 숫자로 끝난다.

## 2. 사용자

- **수간호사(관리자) 1유형.** 로그인 없이 사내망에서 연다. 생성 · 바꾸기 · 확정을 한다. 팀원은 같은 화면을 읽기만 한다(이 편은 권한을 다루지 않는다 — 8 범위 밖).

## 3. 기능 요구사항

| 번호 | 기능 | MoSCoW | Phase |
|---|---|---|---|
| F1 | 월 달력: 날마다 당직자 1명, 제외일 표시, 주말 구분 | Must | 1 |
| F2 | 생성: 월을 고르고 '생성' → 서버가 R1~R6 대로 한 달을 채운다 | Must | 1 |
| F3 | 바꾸기: 두 날짜를 골라 당직자를 서로 교환 — 서버가 규칙 검사 | Must | 1 |
| F4 | 통계: 사람마다 총 횟수 · 주말 횟수 | Must | 1 |
| F5 | 확정: 확정한 달은 다시 생성할 수 없다(바꾸기는 된다) | Must | 1 |
| F6 | API: `GET /api/staff` · `GET /api/unavailable?month=` · `GET /api/roster?month=` · `POST /api/roster/generate` · `POST /api/roster/swap` · `POST /api/roster/confirm` · `GET /api/stats?month=` | Must | 1 |

## 4. 화면

한 페이지(`/`). 위에서 아래로:

- **위:** 제목 `한빛요양병원 3병동 당직 순번표`, 월 선택(`data-testid="month"`, `YYYY-MM`), 생성 버튼(`data-testid="generate-btn"`), 확정 버튼(`data-testid="confirm-btn"`), 상태 글자(`data-testid="status"`: `미생성` · `생성됨` · `확정`).
- **가운데 (왼쪽):** 월 달력. 날마다 칸 하나 `data-testid="day"`, 속성 `data-date="YYYY-MM-DD"`, `data-name="당직자 이름"`(없으면 빈 문자열), 주말 칸은 `data-weekend="1"`. 칸 안에 날짜 · 당직자 · 그날 제외자 이름(작게). 칸을 두 개 고르면 바꾸기 버튼(`data-testid="swap-btn"`).
- **가운데 (오른쪽):** 통계 표. 사람마다 행 `data-testid="stat-row"`, 속성 `data-name`, `data-total`, `data-weekend`.
- **아래:** 메시지 줄(`data-testid="message"`). 서버가 거부하면 `detail` 그대로.
- **미생성 상태:** 달력 칸은 있고 `data-name=""`, 가운데 안내 `아직 순번이 없습니다 — 생성을 누르세요`.
- **오류 상태:** API 가 실패하면 `불러오지 못했습니다` 와 다시 시도 버튼.
- 시각 요소 이름은 완료 기준 테스트가 집는 손잡이다. 바꾸지 않는다.

## 5. 데이터

- **원본:** 프로젝트 루트 `seed/` CSV 3개. 서버는 **시작할 때마다** CSV 를 읽어 SQLite(`duty.db`)를 **새로** 만든다. 생성 · 바꾸기 · 확정 결과는 DB 에 쓴다.
  - `seed/staff.csv` — `name, grade(선임|일반)`
  - `seed/unavailable.csv` — `name, date(YYYY-MM-DD), reason(휴가|교육|병가)` — 그날은 그 사람을 배정하지 않는다
  - `seed/roster.csv` — `date, name, confirmed(0|1)` — 이미 짜인 달(지난달)의 순번. 이달 생성 때 **지난달 마지막 날**과의 연속을 검사하는 데 쓴다
- **테이블:** 접두어 `dt_` — `dt_staff` · `dt_unavailable` · `dt_roster`. 칸은 CSV 와 같다.
- **가상 데이터:** 직원 6명, 제외일 6건, 지난달(2026-10) 순번 31일치. **같은 CSV 를 다른 내용으로 바꿔 끼울 수 있어야** 한다.
- **API**
  - `GET /api/staff` → `[{"name":"김민수","grade":"선임"}, ...]`
  - `GET /api/unavailable?month=2026-11` → `[{"name":"박지연","date":"2026-11-03","reason":"휴가"}, ...]`
  - `GET /api/roster?month=2026-11` → `{"month":"2026-11","status":"미생성|생성됨|확정","days":[{"date":"2026-11-01","name":"최유나","weekend":true}, ... 그 달의 모든 날 ...]}` (미생성이면 `name` 은 `""`)
  - `POST /api/roster/generate` 본문 `{"month":"2026-11"}` → 200 과 roster. 확정된 달이면 409 `확정된 달은 다시 생성할 수 없습니다`. 규칙을 만족하는 배정이 불가능하면 422 `규칙을 만족하는 순번을 만들 수 없습니다`.
  - `POST /api/roster/swap` 본문 `{"date_a":"2026-11-10","date_b":"2026-11-20"}` → 200 과 roster. 거부: 400(없는 날짜 · 같은 날짜 · 미생성 달) · 409(바꾸면 R2 · R3 위반 — 어느 규칙인지 `detail` 에)
  - `POST /api/roster/confirm` 본문 `{"month":"2026-11"}` → 200. 미생성이면 400.
  - `GET /api/stats?month=2026-11` → `[{"name":"김민수","total":5,"weekend":2}, ...]` (직원 전원, 0 포함)
  - 거부 응답은 모두 `{"detail": "사유"}`.

## 6. 업무 규칙

생성 알고리즘은 코드가 아니라 **아래 글**이 기준이다. 어떤 방법으로 채워도 R1~R6 을 모두 만족해야 한다.

| 번호 | 규칙 |
|---|---|
| R1 | **매일 정확히 1명.** 그 달의 모든 날에 당직자가 있고, 하루에 한 명이다. |
| R2 | **제외일 금지.** `unavailable` 에 있는 사람은 그날 배정하지 않는다. |
| R3 | **연속 금지.** 같은 사람이 이틀 연속 당직하지 않는다. **지난달 마지막 날**(`roster.csv`)과 이달 1일도 연속으로 본다. |
| R4 | **총 횟수 공평.** 한 달 안에서 사람별 배정 횟수의 최댓값 − 최솟값 ≤ 1. |
| R5 | **주말 공평.** 토 · 일 배정 횟수의 최댓값 − 최솟값 ≤ 1. |
| R6 | **바꾸기는 규칙 안에서만.** 두 날짜의 당직자를 교환한 결과가 R2 · R3 을 어기면 409 (R4 · R5 는 교환으로 바뀌지 않는다 — 횟수는 그대로이고 주말 ↔ 평일 교환은 허용한다). |
| R7 | **확정은 잠금.** 확정된 달은 재생성 409. 바꾸기는 확정 뒤에도 된다(현장 사정). |
| R8 | **거부가 둘 이상 해당하면** 400(입력 오류) → 409(규칙 위반) 순서로 먼저 걸리는 것 하나만 알린다. |

## 7. 제약

- 스택: **Python FastAPI + 순수 HTML/JS(프레임워크 · 빌드 도구 없음) + SQLite.** 알고리즘은 표준 라이브러리로(외부 최적화 패키지 금지).
- 실행: 프로젝트 루트에서 `python -m uvicorn main:app --port 8000` (`main.py` 에 `app = FastAPI()`). 포트는 환경 변수 `PORT` 가 있으면 그것.
- 생성은 3초 안에 끝나야 한다(6명 × 31일).
- 외부 네트워크 · CDN 없음. 외부 패키지는 `fastapi` · `uvicorn` 만. 한글 UI.

## 8. 범위 밖 (Won't)

- 로그인 · 권한(누구나 생성 가능 — 이 편은 규칙이 주제), 주간 · 야간 2교대 이상, 희망 근무 신청, 바꾸기 '요청 → 승인' 흐름(바로 교환), 공휴일 · 명절 가중치, 알림 · 메신저, 인쇄 · 엑셀, 여러 병동, 다크 모드.
