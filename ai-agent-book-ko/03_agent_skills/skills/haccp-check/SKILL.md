# HACCP 일일 점검표

생산동 · 물류센터 위생 점검을 매일 같은 형식으로 남긴다.

## 점검 항목
1. 냉동창고 온도: -18℃ 이하 (2시간마다 기록)
2. 냉장창고 온도: 0~10℃
3. 작업자 위생: 위생복 · 모자 · 마스크 · 손 세척 기록
4. 이물 관리: 금속 검출기 작동 확인 (시작 · 점심 · 종료 3회)
5. 세척 · 소독: 작업대 · 칼 · 도마 소독 기록
6. 방충 · 방서: 포충등 점검, 출입문 닫힘

## 기록 형식
`{항목} | {기준} | {측정값} | 적합/부적합 | {조치}`
- 부적합이면 조치와 재측정 값을 반드시 쓴다
- 온도는 소수점 한 자리까지

## 부적합 시 보고
- 냉동창고 -15℃ 초과가 30분 넘게 이어지면 즉시 품질팀장에게 전화
- 금속 검출기 고장 시 해당 시간 생산품 보류
