# 주간 영업 보고 PPT

영업팀이 매주 금요일 팀장 회의에 올리는 주간 보고 슬라이드를 만든다.

## 슬라이드 구성 (반드시 5장, 이 순서)
1. 표지 — 제목은 `주간 영업 보고 | {기간}` (예: `주간 영업 보고 | 10/13~10/17`)
2. 매출 요약 — 이번 주 총매출, 목표 대비 달성률(%) 한 줄, 지난주 대비 한 줄
3. 품목별 실적 — 품목마다 `품목: 실적 / 목표 (달성률)` 한 줄씩
4. 이슈 · 조치 — 이슈마다 `이슈 → 조치` 한 줄
5. 다음 주 할 일 — 제목은 정확히 `다음 주 할 일`, 할 일마다 `할 일 (담당)` 한 줄

## 숫자 표기
- 금액은 모두 **만원** 단위, 천 단위 쉼표 (예: 1,240만원). 원 단위로 쓰지 않는다.
- 달성률은 소수점 없이 반올림 (예: 113%).
- 데이터에 없는 숫자는 만들지 않는다. 없으면 `자료 없음` 이라고 쓴다.

## 만드는 방법
1. 받은 데이터를 위 5장 구성에 맞춰 개요 JSON 으로 정리한다.
   `{"file": "weekly.pptx", "slides": [{"title": "...", "bullets": ["...", "..."]}, ...]}`
2. `run_script` 로 이 스킬의 `scripts/make_ppt.py` 를 실행하고, input 에 개요 JSON 을 그대로 넘긴다.
3. 스크립트가 돌려준 장 수가 5가 아니면 개요를 고쳐 다시 실행한다.
4. 사용자에게는 파일 이름과 장별 제목만 짧게 알려 준다.

색 · 글꼴 · 차트 규칙이 필요하면 `reference.md` 를 읽는다. 대부분은 스크립트 기본값으로 충분하다.
