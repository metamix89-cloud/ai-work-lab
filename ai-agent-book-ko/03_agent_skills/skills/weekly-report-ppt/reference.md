# 주간 보고 디자인 규칙 (참고)

- 배경: 진한 남색 #111318, 강조색 인디고 #6366F1, 달성 초과는 초록 #10B981, 미달은 빨강 #EF4444
- 글꼴: 제목 Pretendard Bold 32pt, 본문 Pretendard 20pt. 한 장에 글머리 5줄 이하
- 표지에는 로고 자리만 비워 두고 사진은 넣지 않는다
- 차트가 필요하면 막대그래프 하나만. 원그래프는 쓰지 않는다
- 품목이 6개를 넘으면 상위 5개 + `기타` 로 묶는다
- 회의 화면은 16:9. 4:3 으로 만들지 않는다
- 슬라이드 번호는 오른쪽 아래, 표지에는 넣지 않는다
- 발표 시간은 3분 기준. 장마다 말할 내용은 노트에 한 줄로
