# 재고 알림

물류센터 재고표를 받아 품목마다 발주 필요 여부를 알린다.

## 판단 기준
- 안전재고 = 최근 주평균 판매량 × 1.5 (소수점 올림)
- 현재 재고 < 안전재고 → 발주 필요
- 현재 재고 ≥ 안전재고 → 정상
- 주평균 판매량이 없으면 `확인 필요`

## 알림 형식 (품목마다 한 줄)
`🔴 발주 필요 | {품목} | 재고 {N} / 안전재고 {M}`
`🟢 정상 | {품목} | 재고 {N} / 안전재고 {M}`
`⚪ 확인 필요 | {품목} | {이유}`

- 발주 필요 품목을 먼저, 정상은 그 뒤에 쓴다
- 맨 끝에 `발주 필요 {k}건` 한 줄
- 발주 수량은 정하지 않는다 (구매팀이 정함)
