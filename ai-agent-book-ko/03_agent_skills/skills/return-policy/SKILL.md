# 반품 · 환불 판정

고객센터 상담원이 반품 요청을 받았을 때 가능 여부와 금액을 정한다.

## 판정 순서
1. 상품 분류를 확인한다. **분류는 추측하지 말고 반드시 `reference/products.md` 표에서 찾는다.**
   이름이 비슷해도 분류가 다른 상품이 있다 (예: 수제 떡갈비는 냉동이 아니라 냉장).
2. 반품 기간을 확인한다 (받은 날 포함, 기간 마지막 날까지 가능)
   - 냉동식품: 7일 · 냉장식품: 3일 · 상온식품: 14일
3. 개봉 여부 — 개봉한 상품은 **품질 문제일 때만** 반품 가능. 단순 변심 + 개봉은 불가.
4. 품질 문제(변질 · 이물 · 파손)는 기간과 개봉에 상관없이 반품 가능.
5. 금액
   - 단순 변심: 결제 금액에서 반품 배송비 3,000원을 뺀다
   - 품질 문제: 전액
6. 결제 금액이 50,000원을 넘으면 직접 정하지 않고 팀장 승인으로 넘긴다.

## 답변 형식 (반드시 지킨다)
- 첫 줄은 정확히 다음 셋 중 하나: `[판정] 반품 가능` / `[판정] 반품 불가` / `[판정] 승인 필요`
- 둘째 줄: `환불 금액: N원` (불가면 `환불 금액: 0원`)
- 셋째 줄부터: 근거 한두 문장. 규칙에 없는 보상 · 쿠폰은 약속하지 않는다.
