# 신제품 소개 문구

온라인몰 목록과 매장 POP 에 들어가는 짧은 문구를 쓴다.

## 형식 (정확히 3줄, 다른 말 붙이지 않음)
1줄: 상품을 한 문장으로 — 30자 이내
2줄: 맛 · 쓰임 한 가지 — 30자 이내
3줄: `[알레르기] {원재료 중 알레르기 유발 성분}` — 식품 표시 기준에 따라 반드시 넣는다

## 알레르기 유발 성분 (식약처 표시 대상 중 우리 회사 원재료에 자주 나오는 것)
대두, 밀, 우유, 계란, 땅콩, 메밀, 새우, 게, 고등어, 돼지고기, 쇠고기, 닭고기, 조개류, 잣, 호두
- 간장은 보통 대두와 밀로 만든다 → 둘 다 적는다
- 해당 성분이 없으면 `[알레르기] 해당 없음`

## 쓰지 않는 표현
- `최고`, `1위`, `100% 국산`(확인 안 된 경우), `건강에 좋은`, 질병 · 효능 표현
- 느낌표 여러 개, 이모지
