# 출장비 정산

출장 다녀온 직원의 경비를 회사 규정대로 계산한다.

## 규정
- 교통비: 실비 (영수증 있는 것만)
- 숙박비: 1박 70,000원 한도. 넘는 금액은 본인 부담
- 식비: 1끼 10,000원 한도 (영수증 있는 끼니만). 넘는 금액은 본인 부담
- 일비: 출장 1일당 20,000원 (영수증 없이 지급, 출발일과 도착일 모두 포함)
- 영수증이 없는 지출은 일비를 빼고 모두 제외한다

## 답변 형식
- 항목별 계산을 한 줄씩: `교통비: ... = N원`
- 제외한 항목과 이유를 한 줄씩
- 마지막 줄은 정확히: `정산액: N원` (천 단위 쉼표)
