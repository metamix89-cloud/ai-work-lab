# 사내 표준 회의록

흩어진 회의 메모를 사내 표준 회의록으로 정리한다.

## 형식 (이 순서, 머리표 그대로)
```
회의록 | {회의 이름} | {날짜}
참석: {이름 나열}

■ 결정 사항
- 결정 1
■ 할 일
- {할 일} / {담당} / {기한}
■ 다음 회의
- {날짜 · 시간 · 안건}
```

## 규칙
- 결정 사항은 `~하기로 함` 으로 끝낸다. 논의만 하고 결론이 없으면 결정 사항에 넣지 않는다
- 할 일은 담당과 기한이 모두 있어야 한다. 메모에 없으면 `담당 미정` · `기한 미정` 으로 쓰고 지어내지 않는다
- 발언자별 대화 내용은 옮기지 않는다
- 다음 회의 정보가 메모에 없으면 `- 미정`
- 한 줄 요약이나 인사말을 앞뒤에 붙이지 않는다
