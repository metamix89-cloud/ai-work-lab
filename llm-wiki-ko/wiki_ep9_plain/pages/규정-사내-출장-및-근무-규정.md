# 사내 출장 및 근무 규정
분류: 규정   갱신: 2026-10-26
출처: policies/사규_2026.md

## 현재 값 / 요약
- 직급 등급은 사원·주임·대리 B 등급, 과장·차장 A 등급, 부장 이상 S 등급이며 계약직은 B 등급을 따른다 (출처: 사규_2026.md, 2026-10-26).
- 출장 숙박비 한도는 1박 기준으로 S 등급 120,000원, A 등급 90,000원, B 등급 70,000원이며, 서울·부산·제주는 각 등급 한도에 20,000원을 추가한다. 한도 초과 금액은 본인 부담이다 (출처: 사규_2026.md, 2026-10-26).
- 출장 일비는 등급 관계없이 하루 20,000원이며 출발일과 도착일 포함, 당일 출장은 10,000원이다. 영수증 없이 지급한다 (출처: 사규_2026.md, 2026-10-26).
- 출장 식비는 1끼 12,000원 한도로 영수증 있는 끼니만 정산하며, 회식비는 출장 식비로 처리하지 않는다. 2026년 7월 1일에 10,000원에서 12,000원으로 상향되었다 (출처: 사규_2026.md, 2026-10-26).
- 출장 교통비는 KTX·고속버스·항공 실비 정산, 항공은 편도 300km 이상 시 일반석만 이용 가능, 자가용은 km당 250원과 통행료 지급한다 (출처: 사규_2026.md, 2026-10-26).
- 출장 신청은 출발 3일 전까지 그룹웨어 양식 TR-101, 해외 출장은 출발 14일 전까지 양식 TR-110으로 본부장 결재를 받는다 (출처: 사규_2026.md, 2026-10-26).
- 출장 정산은 복귀 후 7일 이내 양식 TR-120으로 제출하며, 기한 초과 시 다음 달 급여 정산으로 이월된다 (출처: 사규_2026.md, 2026-10-26).
- 법인카드 월 한도는 S 등급 3,000,000원, A 등급 1,500,000원, B 등급 500,000원이며, 1건 300,000원 초과 결제는 사전 팀장 승인 필요하다 (출처: 사규_2026.md, 2026-10-26).
- 법인카드로 상품권·현금성 자산·개인 물품·유흥업소 결제 금지하며, 위반 시 전액 환수 및 인사위원회 회부한다 (출처: 사규_2026.md, 2026-10-26).
- 연차 휴가는 입사 1년 미만은 1개월 만근 시 1일, 1년 이상 15일, 3년차부터 2년마다 1일 추가 최대 25일이다 (출처: 사규_2026.md, 2026-10-26).
- 연차 신청은 사용 3일 전까지 그룹웨어 양식 HR-201, 반차는 오전(09~13시)·오후(14~18시)로 구분, 당일 신청은 팀장 구두 승인 후 다음 날까지 HR-201 제출한다 (출처: 사규_2026.md, 2026-10-26).
- 경조 휴가는 본인 결혼 5일, 자녀 결혼 1일, 배우자 출산 10일, 부모·배우자 부모 사망 5일, 조부모 사망 3일 유급 휴가다 (출처: 사규_2026.md, 2026-10-26).
- 경조금은 본인 결혼 500,000원, 부모 회갑·칠순 200,000원, 부모·배우자 부모 사망 500,000원, 조부모 사망 200,000원 지급하며, 30일 내 증빙 첨부 신청한다 (출처: 사규_2026.md, 2026-10-26).
- 재택근무는 주 2일까지 가능하며, 전날 18시까지 팀장 승인 필요, 생산·물류 현장 근무자는 제외된다. 2026년 9월 1일 주 1일에서 2일로 확대되었다 (출처: 사규_2026.md, 2026-10-26).
- 유연근무 출근 시각은 08시·09시·10시 중 분기별 선택 가능하며, 핵심 근무 시간은 10~16시, 변경은 분기 시작 7일 전까지 양식 HR-230으로 신청한다 (출처: 사규_2026.md, 2026-10-26).
- 비밀번호는 12자 이상, 90일마다 변경, 최근 5번 이내 재사용 불가, 메신저·메일로 주고받지 않는다 (출처: 사규_2026.md, 2026-10-26).
- 외부 저장장치는 보안팀 등록 장치만 사용 가능하며, 등록은 양식 SEC-07, 1년마다 재점검, 미등록 사용 시 1차 경고, 2차 인사위원회 회부한다 (출처: 사규_2026.md, 2026-10-26).
- 생성형 AI 사용 시 고객 개인정보·거래처 단가·미공개 신제품 정보 입력 금지, 회사 승인 계정에서는 내부 문서 요약 허용, 위반 시 보안 규정 위반 처리한다 (출처: 사규_2026.md, 2026-10-26).
- 보안 사고는 발견 즉시 보안팀 내선 7119 신고, 24시간 내 양식 SEC-12 경위서 제출한다 (출처: 사규_2026.md, 2026-10-26).
- 구매는 1,000,000원 이상 2곳 이상 견적, 10,000,000원 이상 3곳 이상 견적, 1년 내 반복 거래 시 연간 단가 계약 전환한다 (출처: 사규_2026.md, 2026-10-26).
- 구매 결재는 5,000,000원 미만 팀장, 5,000,000원 이상 50,000,000원 미만 본부장, 50,000,000원 이상 대표이사 승인 필요하며, 양식 PU-301 사용한다 (출처: 사규_2026.md, 2026-10-26).
- 거래처 등록은 사업자등록증·통장 사본·위생 인증서(식품 원료 업체만) 제출 후 양식 PU-310으로 등록하며, 등록 전 발주 불가하다 (출처: 사규_2026.md, 2026-10-26).
- 고객 반품 판정 기준은 냉동 7일, 냉장 3일, 상온 14일 이내이며, 개봉품은 품질 문제 시만 반품 가능, 단순 변심은 배송비 3,000원 차감, 50,000원 초과 시 팀장 승인 필요하다 (출처: 사규_2026.md, 2026-10-26).
- 생산 작업장 출입 시 위생복·모자·마스크 착용, 손 세척 30초 후 에어샤워, 반지·시계·휴대폰 반입 금지한다 (출처: 사규_2026.md, 2026-10-26).
- 냉동창고 온도는 -18℃ 이하 유지, 2시간마다 기록, -15℃ 초과 30분 이상 시 품질팀장에게 즉시 연락하며, 부재 시 생산본부장에게 연락한다 (출처: 사규_2026.md, 2026-10-26).
- 식품 취급 직원은 매년 건강 진단(보건증) 갱신하며, 미갱신 시 생산 작업장 출입 불가하다 (출처: 사규_2026.md, 2026-10-26).
- 법정 의무 교육은 매년 성희롱 예방·개인정보 보호·산업안전·장애인 인식 개선 교육을 받으며, 미이수자는 연말 평가 감점 대상이다 (출처: 사규_2026.md, 2026-10-26).
- 직무 교육비는 연 1,000,000원까지 지원하며, 양식 HR-260으로 신청, 수료 후 2주 내 수료증 제출, 미수료 시 교육비 반납한다 (출처: 사규_2026.md, 2026-10-26).
- 사내 동호회는 회원 10명 이상 등록 가능하며, 1인당 월 10,000원 지원, 총무팀에 양식 GA-501로 등록한다 (출처: 사규_2026.md, 2026-10-26).
- 업무용 차량은 하루 전 그룹웨어 예약, 운행 후 주행거리 및 주유 영수증 운행일지 기록, 사고 시 보험사 및 총무팀에 즉시 알린다 (출처: 사규_2026.md, 2026-10-26).
- 본사 주차 지원은 임원·장애인·임산부·카풀(3인 이상) 차량에 한하며, 양식 GA-520으로 신청한다 (출처: 사규_2026.md, 2026-10-26).
- 건강검진은 만 40세 이상 매년, 미만은 2년마다 실시하며, 회사 지원 한도는 1인 500,000원, 배우자는 2년마다 300,000원까지 지원한다 (출처: 사규_2026.md, 2026-10-26).
- 자녀 학자금은 고등학생 실비 지원, 대학생은 학기당 1,000,000원까지 2명 한도다 (출처: 사규_2026.md, 2026-10-26).
- 사내 식당 중식은 무료, 석식은 야근 신청자만 무료이며, 야근 신청은 17시까지 그룹웨어에서 한다 (출처: 사규_2026.md, 2026-10-26).
