# 정 대리 개인 메모 (고객센터)
분류: 고객센터   갱신: 2026-10-26

## 현재 값
- 3만 원 넘는 환불은 팀장님께 말로 확인 (시스템엔 승인 칸 없음).
- 11월부터 환불 기간이 14일로 바뀐다는 안내가 있으나, 현재는 7일이 맞음.
- 냉동 회수는 시스템 버튼이 작동하지 않아 택배사(한빛물류) 사이트에 직접 입력해야 함.
- 반품이 잦은 고객은 개인 엑셀 '주의 고객' 시트를 확인.
- 지방 냉동 건은 월요일과 화요일 출고만 가능 (2026-10-13 회의 이후).
- 사내 시스템 초기 비밀번호는 "Ganada!2026"이며, 신입 직원에게 알려 줌.

## ⚠ 상충 · 확인 필요
- 11월 환불 기간 변경 여부: 현재는 7일이 맞으나 11월부터 14일로 변경 예정인지 팀장 확인 필요.
- 오 과장 연봉 5,200 관련 내용은 인사팀 메신저 오보 가능성 있음.
